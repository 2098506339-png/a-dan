# 豌豆 · AI 漫剧作品集

这是 React + Vite 静态网站，包含中英双语介绍、AI 漫剧经历、精选项目、能力展示、作品视频和动画效果。

## 本地预览

安装依赖后运行 `pnpm dev`。运行 `pnpm build` 会生成 `dist/index.html` 及网站资源；`pnpm preview` 可预览生产构建。

## Cloudflare Pages

- GitHub 仓库：`2098506339-png/a-dan`
- 生产分支：`master`
- 构建命令：`npm run build`
- 构建输出目录：`dist`

页面使用纯静态资源，不需要 Worker 或服务端环境变量。首页背景视频位于 `public/assets/wandou-homepage-0914.mp4`。
